# Настройка Telegram: бот, Mini App, вход через Telegram

Всё настраивается через официального бота **[@BotFather](https://t.me/BotFather)**. Часть настроек (команды, кнопка «Магазин», webhook) сервер выставляет сам при запуске. Вручную нужно сделать только то, что описано ниже.

## 1. Создать бота

1. Откройте [@BotFather](https://t.me/BotFather) и нажмите **Start**.
2. Отправьте `/newbot`.
3. **Имя** — то, что видят люди, например `chebu store`.
4. **Username** — должен заканчиваться на `bot`, например `chebustore_bot`. Если занят, подберите другой.
5. BotFather пришлёт **токен** вида `7123456789:AAH...`. Это пароль от бота:
   - впишите его в `.env` на сервере: `TELEGRAM_BOT_TOKEN=7123456789:AAH...`;
   - username без `@` впишите в `TELEGRAM_BOT_USERNAME=chebustore_bot`;
   - больше нигде токен не храните и никому не отправляйте.

## 2. Оформить профиль бота

В @BotFather отправьте `/mybots` → выберите бота → **Edit Bot**:

| Пункт | Что указать |
|-------|-------------|
| **Edit Name** | `chebu store` |
| **Edit About** (до 120 символов, видно в профиле) | `Магазин одежды chebu store. Каталог, заказы и уведомления о доставке.` |
| **Edit Description** (экран до нажатия Start) | `Здесь можно выбрать одежду, оформить заказ и следить за его статусом. Нажмите «Запустить», затем «Магазин».` |
| **Edit Botpic** | Аватарка магазина из репозитория: `docs/brand/avatar.jpg` (640×640) |
| **Edit Description Picture** | Необязательно, картинка 640×360 |

Команды (`/start`, `/orders`, `/help`) задавать вручную не нужно: сервер регистрирует их сам.

## 3. Привязать домен — обязательно для входа на сайте

Без этого шага кнопка «Войти через Telegram» на сайте покажет ошибку **Bot domain invalid**.

1. В @BotFather отправьте `/setdomain`.
2. Выберите бота.
3. Отправьте `chebustore.ru` — без `https://` и без `/`.

Ответ `Success! Domain updated.` — готово.

## 4. Mini App

Mini App — это сайт магазина, открытый внутри Telegram. Внутри Mini App вход происходит автоматически через Telegram, а вход по почте скрыт.

### 4.1. Кнопка «Магазин» в чате — уже работает

При запуске сервер сам ставит боту кнопку меню **«Магазин»** слева от поля ввода. Команда `/start` отвечает кнопкой «Открыть магазин». Ничего делать не нужно.

### 4.2. Главное Mini App бота — рекомендуется

Добавляет большую кнопку **«Открыть»** в профиль бота и выводит бота в поиске приложений Telegram.

`/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → отправьте URL:

```
https://chebustore.ru/
```

### 4.3. Прямая ссылка на магазин — необязательно

Для ссылок в сторис, канале и рекламе вида `t.me/chebustore_bot/shop`:

1. `/newapp` → выберите бота.
2. Название: `chebu store`; описание: `Магазин одежды`.
3. Фото 640×360 (обязательно): готовая картинка `docs/brand/miniapp-cover.jpg`. GIF — пропустите командой `/empty`.
4. URL: `https://chebustore.ru/`
5. Короткое имя: `shop`.

Ссылка: `https://t.me/chebustore_bot/shop`. Её можно публиковать где угодно.

### 4.4. Кнопка в Telegram-канале магазина

В посте канала добавьте кнопку-ссылку на `https://t.me/chebustore_bot/shop` (из шага 4.3) или на `https://t.me/chebustore_bot?start=shop`.

## 5. Команды и кнопка меню

Выставляются сервером автоматически при каждом запуске:

| Команда | Что делает |
|---------|------------|
| `/start` | Приветствие и кнопка «Открыть магазин» |
| `/orders` | 5 последних заказов со статусами. Каждая кнопка открывает заказ в Mini App |
| `/help` | Подсказка |

Если вы меняли кнопку меню вручную в @BotFather, сервер вернёт свою при следующем перезапуске.

## 6. Узнать свой Telegram ID и стать администратором

1. Напишите боту [@userinfobot](https://t.me/userinfobot). Он ответит вашим **Id**, например `123456789`.
2. Впишите его в `.env`: `BOOTSTRAP_ADMIN_TELEGRAM_IDS=123456789`. Несколько ID — через запятую.
3. Перезапустите: `docker compose up -d`.
4. Войдите на сайте через Telegram или откройте Mini App — вы администратор.

Либо командой на сервере, без перезапуска:

```bash
docker compose exec api node dist/scripts/makeAdmin.js 123456789 ADMIN
```

Сотрудникам, которые входят по почте, нужно один раз привязать Telegram на сайте: **Профиль → Telegram → Привязать**. Иначе чеки им в Telegram приходить не будут, и кнопки подтверждения для них работать не будут.

**Каждый сотрудник должен хотя бы раз нажать Start у бота**: Telegram запрещает ботам писать первыми.

## 7. Куда приходят чеки: лично или в группу

Когда покупатель прикрепляет чек, бот присылает сотрудникам фото или PDF чека с кнопками:

```
🧾 Чек по заказу №1024
Сумма к оплате: 5 990 ₽
Иван, +7 999 123-45-67

[✅ Оплата получена]
[Платёж не найден] [Сумма не совпадает]
[Открыть в админке]
```

После нажатия сообщение обновляется: кто и что решил. Покупатель сразу получает уведомление. Нажать кнопку может только сотрудник с ролью Менеджер или Администратор и привязанным Telegram. Для остальных бот ответит «Нет доступа», даже если они видят сообщение.

Также приходят уведомления о новых заказах.

### Вариант А: лично каждому (по умолчанию)

Оставьте `TELEGRAM_ADMIN_CHAT_ID` пустым. Уведомления получают в личку все менеджеры и администраторы с привязанным Telegram.

### Вариант Б: в закрытую группу команды

Удобно, когда сотрудников несколько: все видят, кто уже проверил чек.

1. Разрешите боту вступать в группы: `/mybots` → бот → **Bot Settings** → **Allow Groups?** → **Turn groups on**.
2. Создайте **закрытую** группу, добавьте в неё сотрудников и бота.
3. Узнайте ID группы: временно добавьте в неё [@getidsbot](https://t.me/getidsbot) (или [@RawDataBot](https://t.me/RawDataBot)). Он напишет ID вида `-1001234567890`. Затем удалите этого бота из группы.
4. Впишите в `.env`: `TELEGRAM_ADMIN_CHAT_ID=-1001234567890` и выполните `docker compose up -d`.
5. **Снова запретите группы**: **Allow Groups?** → **Turn groups off**, чтобы бота нельзя было добавить в чужие чаты. Из вашей группы бот не удалится.
6. Режим приватности (**Group Privacy**) оставьте **включённым**: боту не нужно читать переписку группы, кнопки работают и так.

> Группа должна быть закрытой: в ней видны телефоны покупателей и чеки. Удаляйте из неё уволенных сотрудников и сразу меняйте им роль на «Покупатель» в админке.

## 8. Проверка работы

1. **Webhook.** Откройте в браузере (подставьте токен; ссылку никому не показывайте):
   ```
   https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
   ```
   Должно быть `"url":"https://chebustore.ru/api/telegram/webhook"`, `pending_update_count` близко к 0, поля `last_error_message` нет.
2. **Бот.** Напишите боту `/start` — придёт приветствие с кнопкой.
3. **Mini App.** Нажмите «Магазин» — откроется каталог, в профиле вы уже авторизованы.
4. **Сайт.** На https://chebustore.ru → Профиль → «Войти через Telegram» → подтвердите во всплывающем окне или в Telegram.
5. **Уведомления.** Оформите тестовый заказ на 1 товар, прикрепите любое фото как чек. Сотрудникам придёт сообщение с кнопками. Нажмите «Платёж не найден» — покупателю придёт уведомление с причиной. Затем отмените заказ в админке, чтобы вернуть товар на склад.
6. **iPhone.** В приложении: Профиль → «Войти через Telegram» → откроется окно входа → после подтверждения вы вернётесь в приложение авторизованным.

## 9. Как устроен вход через Telegram

Все проверки подписи идут на сервере, клиентам токен бота не нужен.

| Где | Как |
|-----|-----|
| **Сайт** | Официальный виджет Telegram Login. Telegram подписывает данные пользователя ключом, производным от токена бота. Сервер проверяет подпись и срок (24 ч), одни и те же данные повторно использовать нельзя. Затем выдаётся `httpOnly` cookie |
| **Mini App** | Telegram передаёт в Mini App подписанные `initData`. Сервер проверяет подпись (HMAC с ключом `WebAppData`) и выдаёт токен, который живёт только в памяти вкладки |
| **iPhone** | Защищённое окно Safari открывает `chebustore.ru/auth/app` → вход виджетом → сайт выдаёт одноразовый код (живёт 2 минуты) и возвращает в приложение → приложение меняет код на токен с проверкой PKCE → токен в Keychain |

Дополнительно:
- При входе на сайте виджет запрашивает разрешение писать вам — это нужно для уведомлений о заказах.
- При каждом новом входе в аккаунт бот присылает сообщение «Новый вход». Если это были не вы — **Профиль → Устройства → Завершить все другие сеансы**.
- Почта и Telegram могут быть привязаны к одному аккаунту: привязка делается в профиле на сайте. Отвязать Telegram можно только при привязанной почте, чтобы не потерять доступ к аккаунту.

## 10. Безопасность бота

- Токен хранится только в `.env` на сервере. Если он утёк (попал в чат, скриншот, git):
  1. @BotFather → `/mybots` → бот → **API Token** → **Revoke current token**;
  2. новый токен — в `.env`;
  3. `docker compose up -d` — сервер сам заново зарегистрирует webhook.
- Webhook принимает запросы только с секретным заголовком `TELEGRAM_WEBHOOK_SECRET`. Поддельные запросы отклоняются.
- Не запускайте боевого бота на своём компьютере (`npm run dev` с боевым токеном): это снимет webhook с сервера. Для разработки создайте отдельного тестового бота.
- Не добавляйте в @BotFather других владельцев без необходимости (**Transfer Ownership** не используйте).
- Включите в своём Telegram двухэтапную аутентификацию (Настройки → Конфиденциальность → Облачный пароль): владелец Telegram-аккаунта управляет и ботом, и админкой.

## 11. Частые проблемы

| Проблема | Решение |
|----------|---------|
| **Bot domain invalid** | Выполните `/setdomain` → `chebustore.ru` (раздел 3) |
| Виджет входа не появляется на сайте | Проверьте `TELEGRAM_BOT_USERNAME` в `.env` (без `@`) и перезапустите. Иногда Telegram блокирует окно входа в режиме инкогнито — попробуйте обычное окно |
| Бот молчит на `/start` | Проверьте `getWebhookInfo` (раздел 8) и `docker compose logs api` |
| `last_error_message: Wrong response from the webhook: 403` | `TELEGRAM_WEBHOOK_SECRET` изменили без перезапуска — выполните `docker compose up -d` |
| Покупателю не приходят уведомления | Покупатель не нажимал Start у бота или заблокировал его. Уведомления на почту при этом всё равно приходят, если почта привязана |
| Сотрудник нажимает кнопку — «Нет доступа» | У него роль «Покупатель» или не привязан Telegram в профиле |
| Mini App открывается, но не авторизует | Mini App должен открываться по адресу `https://chebustore.ru/` (с https). Откройте его кнопкой бота, а не ссылкой в браузере |
| В Mini App старая версия сайта | Закройте Mini App полностью и откройте снова. Кэш HTML отключён, но Telegram может держать открытую копию |
