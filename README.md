# chebu store

Интернет-магазин одежды: сайт **chebustore.ru**, Telegram-бот с Mini App, приложение для iPhone и админка. Всё работает от одного сервера.

```
chebustore/
├── server/            API: Node.js 22, Fastify, Prisma, PostgreSQL, Telegram-бот (grammY)
├── web/               Сайт + Telegram Mini App + веб-админка (React, Vite)
├── ios/               Приложение для iPhone (SwiftUI, iOS 17+) с админкой
├── deploy/            Caddy (HTTPS, заголовки безопасности) и сборка сайта
├── docker-compose.yml Запуск всего на сервере одной командой
├── .env.example       Шаблон серверных секретов
└── docs/
    ├── INSTALL.md     Полная установка, обновление, бэкапы, iOS
    └── TELEGRAM.md    Настройка бота, Mini App, входа через Telegram
```

## Что умеет

**Покупатель**
- Каталог с категориями, поиском и сортировкой, карточка товара с фото и размерами.
- Корзина и оформление заказа: самовывоз, курьер или почта/ПВЗ.
- Оплата переводом: покупатель видит реквизиты СБП/карты внутри своего заказа, переводит и прикрепляет чек (фото или PDF).
- Статусы заказа с уведомлениями в Telegram и на почту:
  `Ожидает оплаты → Проверяем оплату → Собирается → В доставке → Можно забрать → Получен` (или `Отменён`).
- Вход:
  - **сайт** — через Telegram или по коду на почту;
  - **Mini App** — автоматически через Telegram (только Telegram);
  - **iPhone** — через Telegram или по коду на почту.
- Профиль: привязка второго способа входа, список устройств, «выйти на всех устройствах».

**Команда магазина** (роли `Менеджер` и `Администратор`)
- Проверка чеков в админке (сайт/iPhone) или прямо в Telegram кнопками «Оплата получена / Отклонить».
- Смена статусов, трек-номер, инструкция для самовывоза, внутренние заметки.
- Товары: фото, варианты размер/цвет, остатки, цены и скидки, скрытие.
- Категории, настройки магазина и доставки.
- Только администратор: реквизиты оплаты, роли и блокировка пользователей, журнал действий.

## Безопасность — коротко

- **Все секреты только на сервере** в файле `.env`: токен бота, SMTP, ключ подписи, пароль базы. В сайте, Mini App и iOS-приложении нет ни одного ключа. Реквизиты оплаты отдаются только владельцу неоплаченного заказа и сотрудникам.
- Сессии — случайные токены; в базе хранится только их HMAC. На сайте токен лежит в `httpOnly`, `Secure`, `SameSite` cookie (недоступна JavaScript). В Mini App токен живёт только в памяти, в iOS — в Keychain («только на этом устройстве»).
- Вход через Telegram проверяется подписью на сервере. Для виджета есть защита от повторного использования, для Mini App — проверка `initData`, для iOS — PKCE.
- Код на почту: 6 цифр, 10 минут, 5 попыток, лимиты на отправку. По ответу нельзя узнать, есть ли такой аккаунт.
- Защита от CSRF (проверка Origin + обязательный заголовок), ограничение частоты запросов, строгие CORS/CSP/HSTS.
- Проверка прав на каждом запросе: покупатель видит только свои заказы и чеки. Смена роли или блокировка мгновенно завершает все сессии пользователя.
- Чеки хранятся приватно и отдаются только владельцу и сотрудникам. Изображения перекодируются: метаданные и геолокация удаляются, подделанные файлы отсекаются.
- Контейнеры: база в изолированной сети без доступа снаружи, API — read-only файловая система, без привилегий.
- Журнал действий сотрудников: подтверждения оплат, смена реквизитов, ролей, статусов.

## Быстрый старт

1. Сервер с Docker, домен `chebustore.ru` указывает на сервер.
2. `cp .env.example .env` и заполнить.
3. `docker compose up -d --build`.
4. Настроить бота в @BotFather.

Подробно по шагам: **[docs/INSTALL.md](docs/INSTALL.md)** и **[docs/TELEGRAM.md](docs/TELEGRAM.md)**.
